# 人物表演与制作字段 v0.1

2026-09-10。本稿落实已确认的码头帮派方向、六类动作与三个首轮观察方向，供整体审看。它是嵌套字段设计及实例走读，不是可执行 JSON Schema，不代表图像或游戏已经更新。需求与确认记录见 [spec.md](spec.md)。

## 1. 分工与完整链路

```text
项目美术约定
  ↓
SceneDesign.elements[]：人物身份、外观、人物表演
  ↓ 选定外观后填写同一人物的动作内容
制作计划：角色引用 + 动作阶段引用 + 观察方向 + 关键帧
  ↓
生图：同一角色、同一方向的短动作图组
  ↓
裁剪结果：源图、实际区域、统一尺度、支撑基准、透明图
  ↓
运行时按动作与方向使用实际关键帧
```

沿用现有 SceneDesign 的人物元素，外观只定义一次。项目美术约定约束画法；人物身份和威胁特征由具体人物定义。游戏中的位移仍属于 `motion`；伤害、敌对触发和寻路仍属于玩法。制作阶段记录结果，不反向把偶然画错的服装或朝向当成新设计。

## 2. 人物与动作的嵌套字段

```text
SceneDesign.elements[]
  id / name / visual_role
  form
    silhouette / proportions
    parts[]: {name, shape, placement}
  surface_uses / representation / integration       沿用已有字段
  performance
    actions[]
      id / name / intent
      target: string | null                        动作对象，角色局部命名
      loop: boolean
      phases[]                                     顺序即表演顺序
        id / intent
        pose
          torso: text
          head: text
          gaze: {target: string | null, manner: text}
          expression: text
          arms_hands: text
          legs_feet: text
          weight: text
        transition: text
      view_readability: text
```

- `visual_role` 写人物身份及可见敌意；脸、发型、衣服、帮派配饰分别展开在 `form.parts`，不要只填“凶狠”。
- 左右均以人物自身为准。`torso` 写相对基准前方或动作对象的扭转、前压与倾斜；`head` 写相对躯干的转动。
- 动作对象与视线对象可以不同。直拳的动作对象可以是 `opponent`，受击时 `gaze.target` 可以是 `null`，回头时可以看向 `rear_sound`。这些名称在制作任务中明确绑定位置，不凭字符串猜坐标。
- 每个阶段的姿态自足，不能只写“同上但抬手”。`transition` 描述两个阶段怎样衔接；循环末段须写接回首段的方式，非循环末段说明回戒备或保持终态。
- 阶段数量按动作需要确定，不要求所有动作都有“预备、攻击、恢复”。行走可以按支撑与迈步分段，倒地可以以横卧终态结束。
- 一阶段可以对应多张关键帧。具体时长、采样数量、帧图布局属于制作计划；只有写明循环并画出循环姿态，才能交付循环动作。
- 旧 `everyday / reactions` 中需要制作的内容转为有名字的动作；旧 `preparation / key_pose / recovery` 转为阶段，不并行保留两套动作定义。历史实例不在本稿中静默迁移。

## 3. 六人造型展开建议

以下是已选帮派方向的具体填写提案。ID 沿用旧人物便于追踪，名称和外观按新身份设计；旧资产尚未替换。共同特征采用暗红布带、无字暗铜扣与硬朗的领肩转折，按角色分配位置；不用文字徽记、武器或相同脸型辨认敌人。

| ID | 新身份 | 个体轮廓与神态 | 共同特征的落点 |
| --- | --- | --- | --- |
| courier | 红衫追债仔 | 瘦长窄腰、短红外套、斜压肩线；抬下巴斜笑，站位侵入通路 | 右腕暗红绑带、腰部暗铜扣；移除送货挎包 |
| porter | 桩头打手 | 宽肩厚臂、硬肩深背心、敞领浅衬衣；眉压低、下颌前送，双脚撑住路中 | 双手旧布绑带、背心暗铜扣 |
| electrician | 冷面截路手 | 利落短发、收腰灰青短夹克，手肘留出尖锐负空间；抿嘴直视、肩先于脚探出 | 上臂暗红带、短夹克暗铜扣；移除工具围裙 |
| boatman | 老练压场人 | 瘦硬肩背、短靛灰外衣、低帽沿；站得稳，抬眼轻蔑审视来人 | 领下暗红布结、腰侧暗铜扣；不沿用佝偻退让的生活姿态 |
| watchman | 长衣头目 | 窄高棕长衣、硬翻领、开襟形成竖直暗面；单侧嘴角上扬，身体占住入口 | 翻领下暗红布条、腰带暗铜扣 |
| cargo_worker | 短打狠手 | 敦实体型、赭黄短衣、紧头巾和厚手套；压低肩头、拳置于身体前方 | 左腕暗红带、衣襟暗铜扣 |

原有性别和成年身份延续，人体比例与漫画画法保持一致。共同气质是主动压迫和挑衅，个人动作节奏则依体型有所区别。

### 纤细角色：回头观察与受击

以下为 `electrician` 的对照走读，使用完全相同的字段。回头观察仅用于检查结构表达能力，不扩大本轮已选动作制作范围。

| 阶段 | torso / head | gaze / expression | arms_hands / legs_feet / weight | transition |
| --- | --- | --- | --- | --- |
| 回头·察觉 | 躯干仍朝前；头先向左后转 | 看 `rear_sound`，眉梢收紧、嘴唇抿住 | 手仍在腰胸之间，没有举拳；双脚不挪，重心在右腿 | 颈部转动带动左肩稍向后开 |
| 回头·查看 | 肩线稍向左打开；头越过左肩 | 继续看 `rear_sound`，带怀疑和不耐烦 | 左肘离开身体，右手压低；左脚跟轻松开，重心仍在右腿 | 未发现目标时肩线复位，再转回头 |
| 受击·偏离 | 肩胸向右后偏；头向右甩开 | `null`，短暂闭眼、嘴角因冲击张开 | 左手本能抬向受击侧，右肘失去紧凑戒备；右脚后退承重 | 膝髋屈曲吸收冲击，左脚重新找支撑 |
| 受击·稳住 | 躯干回中，头逐渐转回对手 | 看 `opponent`，闭口咬紧、重新聚焦 | 双手回到胸颊之间；双脚恢复站距，重心下降 | 接回 guard；若玩法判定倒地则进入 fall |

这两个动作分别使用 `target: rear_sound` 和 `target: opponent`，均为非循环；回头查看允许保持终态后回正，受击稳住接回戒备。生产所需的具体时刻另行取关键帧。

走读结论：注视目标不能固定成 `camera`，手也不能固定成拳；受击时头、躯干、支撑脚与视线的变化可以分别表达。倒地的最终支撑可转为身体侧面，不能强行要求两脚始终贴在同一条线上。

## 5. 观察方向与制作计划

观察方向以人物动作的基准前方为参照，人物做动作时肩腰可以继续转动。`front_left` 指镜头位于人物自身左前方，不是画面左边。

```text
CharacterProductionPlan
  scene_design: {id, revision}
  element_id
  appearance_reference: path | null               选定后填写实际图像
  views[]
    id
    observer_position: text
    framing: text
  shots[]
    id
    action_id / view_id
    target_bindings[]: {id, position}              对手、声音来源等相对于人物的位置
    frames[]
      id / phase_id
      instant: text                               阶段内要画的形态
      hold_ms: number                             制作时的建议停留时长
  canvas
    frame_size_px: [width, height]
    standing_height_px: number                     此角色在固定投影下的基准站高
    anchor_px: [x, y]                              角色根位置在画格中的固定落点
    padding_px: number
    background: text
```

只有实际使用的动作与方向组合才建 `shots`，不生成所有动作乘所有方向的完整矩阵。一个制作计划只对应一个人物与一版外观，`shots` 不重复人物设定。计划引用完整动作阶段，不另编动作。

首轮覆盖已经确认：

| 动作 | 正面 | 左前斜 | 右前斜 | 初次采样建议 |
| --- | --- | --- | --- | --- |
| 威胁待机 | 制作 | 制作 | 制作 | 2 张，轻微重心与肩头变化 |
| 戒备 | 制作 | 制作 | 制作 | 2 张，呼吸与蓄势感 |
| 行走 | 制作 | 制作 | 制作 | 4 张，左右支撑与经过姿态形成循环 |
| 直拳 | 制作 | 暂不制作 | 暂不制作 | 预备、发力、收势各 1 张 |
| 受击 | 制作 | 暂不制作 | 暂不制作 | 冲击偏离、吸收冲击、重新稳住共 3 张 |
| 倒地 | 制作 | 暂不制作 | 暂不制作 | 失衡下落、落地、横卧终态共 3 张 |

这是每人 33 张独立关键帧的初次制作估算；六人共 198 张，不等于要分别调用 198 次生图。实际连贯性检视后可在阶段内增补；不得减少到用单张站姿图代替行走或倒地。动作速度与打击时机最后通过运行片段判断。

正面交战时将 `opponent` 绑定到镜头所在的玩家位置；斜视角观察同一动作时，对手仍位于角色前方，镜头只是在侧方观察。若要表现角色转向新位置的玩家，应另行明确该时刻的对手位置，不能把所有视角都强行画成对视。首轮缺少侧后和背面，不声称覆盖完整绕身观察。

## 6. 生图与裁剪怎样承接

建议先生成六人新外观设定，检查帮派身份与个体差异，再以选定人物单独作为动作参考。先完成 `porter` 的正面动作、左右前斜基础动作与实际裁剪，检视脸、服装、眼神和尺度连续性，再扩展其余五人。

同一张源图只容纳一个人物、一个观察方向的短动作组，按事先指定的画格排列，格内不画文字和编号。画格位置与关键帧 ID 由任务记录对应。按实际分辨率分批，不让六人和几十个姿态挤在同一张小图里。

裁剪产物按以下字段记录，生成之前不填写不存在的源图或输出文件：

```text
CharacterFrameResult
  shot_id / frame_id
  source_image
  crop_rect_px: [x, y, width, height]
  output_image
  output_size_px: [width, height]
  anchor_px: [x, y]
  source_to_output: {scale, offset_px: [x, y]}
  alpha_method: text
```

- 源图需保留手脚、拳头伸展与横卧所需空白。先检查画内动作与眼神，再做去底、裁剪和透明输出。
- 同一角色的所有帧维持同一基准尺寸和投影比例。出拳透视、弯腰和横卧会自然改变可见外接框，不能分别把外接框缩放至相同高度。
- `anchor_px` 是角色根位置在画格里的投影基准。普通站立时它与地面接触相关，迈步或倒地时手脚和身体可相对它移动；不能逐帧以可见最低像素重新定位，抹掉动作本身。
- 去底后检查边缘和真实 alpha。以洋红底作为中间来源时，需清除边缘残色；最后交付真实透明图，并让运行时材质读取其 alpha。
- 记录实际画格区域，不假定生成图一定精确遵守网格。动作内容画错或人物比例漂移需修图或重生，不能靠裁剪掩盖。
- 游戏接入按动作、方向和帧 ID 映射，替代旧的六格数字约定。缺少方向时不把正面纹理标成该方向；首轮转向策略需忠实体现已交付覆盖范围。

## 7. 整体审看结论

两轮已决定的内容已经落到字段、角色造型建议、动作走读与制作覆盖表。走读显示同一结构可以描述重型直拳、纤细回头和受击偏离；这是结构上的表达检查，尚未证明图像一致性或动作连贯性。

整体理解确认后进入：六人新版外观 → 首名角色的动作与裁剪样本 → 其余五人 → 运行时动作及方向映射。历史源图保留；当前未生成新图、修改游戏或建立新的资产管理系统。
