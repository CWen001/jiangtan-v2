# 夜间漫画街区小样

2026-09-09。用户确认采用 Godot、Blender MCP 和 Codex 内置 ImageGen，题材选择原创黑色漫画街区。

## 本轮实现范围

- 一段夜间巷道与相连室内空间。
- 第一人称移动和观察，门与人物互动。
- 原创漫画人物、砖墙、铺地、夜场海报、木纹和唱片封面，由内置 ImageGen 生成。
- Blender 经真实 MCP 调用生产一个街角道具组合，导出供 Godot 使用。
- 一次短小的接头任务，用于检查交互与空间可读性。

人物先以单张正面 sprite 验证透明边缘、遮挡与站立尺度。多方向逐帧动画、战斗、敌人 AI、存档和声音制作属于后续工作，不作为本轮已实现内容。

## 验收

工程能在本机 Godot 打开运行；移动与碰撞有效；门能开启；人物交互能推进任务；原创图片实际被加载；Blender 导出模型实际出现在场景中。保存游戏内图形渲染截图与命令行检查记录。

## 工具边界

内置 ImageGen 的返回文件保留原件并复制到工程，提示词存于 `art/imagegen/`。Blender MCP 的接入与使用证据以 `tools/blender/` 中的实际脚本及日志为准；不将一般 CLI 建模称为 MCP 调用。

本机可运行样例与独立分发安装包分别验收，本轮先交付工程及本机启动入口。
