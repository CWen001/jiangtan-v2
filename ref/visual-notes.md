# Fallen Aces：画面观察与后续讨论

## 用户已明确的方向

做一款借鉴 Fallen Aces 样式的游戏，采用 3D 场景、2D 人物及丰富的贴图表现。这里记录参考分析；没有把美术观察直接升级为项目实现决策。

## 从截图可直接观察的特点

以下为本轮查看 24 张截图后的视觉判断，不是开发者对渲染实现的说明。

| 层次 | 观察 | 建议先看的图 |
| --- | --- | --- |
| 空间结构 | 墙面、楼梯、门洞、栏杆与建筑形成明确透视，街巷有高差和纵深 | 04、08、14、40 |
| 人物表现 | 人物轮廓清晰，粗黑线与大块明暗突出表情、服装和动作剪影 | 00、20、26、34、38 |
| 第一人称手部 | 手和武器占据画面前景，也采用漫画线条与块面阴影 | 02、10、12、44 |
| 表面纹理 | 墙纸、木地板、砖墙、布面和装饰图案承担大量细节 | 18、28、32、38 |
| 场景叙事 | 招牌、画框、电视、筹码和工具让场所具有具体用途与生活痕迹 | 06、28、32、34 |
| 光色组织 | 常见大面积暗部加局部暖光；部分场景使用冷蓝光、红光和发亮窗户突出区域 | 08、18、22、36、40 |

这里的“丰富贴图”可以拆为三个观察对象：重复覆盖墙地面的材质纹理、带有信息的海报招牌等图像、表现人物和物件的 sprite。官方 SDK 对贴花和 sprite 分别提供工具，支持把这些用途分开研究。[S2](sources.md#s2--官方关卡编辑器文档)

画面统一感值得优先研究：人物与环境都带有明显的线条、块面和磨损细节。只把漫画人物放进写实场景，还不足以复现这些截图呈现的整体感觉。这是视觉分析，不是已验证的技术结论。

## 官方资料确认了什么

官方商店强调非线性关卡、潜行和正面战斗，以及把周围物品用于战斗。这意味着如果以后也要学习其玩法，讨论范围会扩展到空间路径和物件交互。[S1](sources.md#s1--官方商店及截图)

官方编辑器文档区分空间、表面贴图、贴花和 sprite；它是研究资产组织方式的直接入口，但不要求本项目使用同一套编辑器。[S2](sources.md#s2--官方关卡编辑器文档)

## 暂时不能据此断言的事情

- 不能仅凭截图确认每类物件究竟是平面 sprite、模型，还是混合表现。
- 尚未核实人物具体有多少方向、每个动作多少帧，以及运行时如何切换朝向。
- 未核实单张纹理尺寸、图集大小、材质数量、绘制调用和性能预算。
- 手绘外观不等于全部素材均用同一种纯逐帧手绘流程制作；官方在 2026 年提到制作流程变化。[S3](sources.md#s3--官方更新公告)

## 看完参考后再讨论

第一项关键选择：希望先验证“走进漫画世界”的视觉效果，还是同时验证近战、潜行和物件交互？这会决定第一版原型的规模。

建议先做一个可行走的小场景，放入一个有动作的人物，用近看、侧看和移动来检查人物与环境是否融合；这是供讨论的建议，尚未确认。题材、美术资产制作方式和运行平台随后再定。
